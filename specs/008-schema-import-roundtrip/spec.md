# Feature Specification: Generic Schema Import with Roundtrip Fidelity

**Feature Branch**: `008-schema-import-roundtrip`
**Created**: 2026-03-11
**Status**: Complete
**Input**: "create a function for importing any json schema and for some schemas (e.g. json, linkml) ensure a roundtrip is possible"

## User Scenarios & Testing *(mandatory)*

### User Story 1 — Generic JSON Schema Import (Priority: P1)

A developer has a JSON Schema file for a domain not covered by any existing adapter (BIDS,
DANDI, NWB, openMINDS, AIND). They want to load it into the ingestion pipeline to extract
`NormalizedElement`s and `SchemaClassPayload`s without writing a new adapter from scratch.

**Why this priority**: Enables ad-hoc schema onboarding — any draft-07/2019/2020 JSON Schema
file should work immediately. Unlocks extensibility without per-source adapter work.

**Independent Test**: Point `GenericJSONSchemaAdapter.load_file()` at an arbitrary fixture
and assert correct NormalizedElement extraction — fully offline, no backend required.

**Acceptance Scenarios**:

1. **Given** a JSON Schema file with top-level `properties` and `$defs`, **When**
   `GenericJSONSchemaAdapter.load_file(path).extract_elements()` is called, **Then** all
   top-level properties and `$defs` entries with properties yield NormalizedElements with
   `source_name="generic-json"` and correct `data_type`.

2. **Given** a JSON Schema containing `$ref` to a `$defs` entry, **When** elements are
   extracted, **Then** the referenced type is resolved (no raw `$ref` string in any field).

3. **Given** a JSON Schema with `enum` values, **When** extracted, **Then**
   `NormalizedElement.allowed_values` contains the enum values as strings.

4. **Given** an empty path or non-existent file, **When** `load_file()` is called, **Then**
   `ValueError` or `FileNotFoundError` is raised.

---

### User Story 2 — LinkML Schema Import (Priority: P2)

A developer has a LinkML YAML schema (generated by `undata generate-schema` or hand-authored)
and wants to import its slots/classes as `NormalizedElement`s to compare against the original
source elements — enabling programmatic diff and regression detection.

**Why this priority**: Required for roundtrip validation (US3). Useful standalone for
auditing exported schemas.

**Independent Test**: Point `LinkMLAdapter.load_file()` at a hand-authored LinkML YAML fixture
and assert elements are extracted — fully offline.

**Acceptance Scenarios**:

1. **Given** a LinkML YAML schema with slot definitions, **When**
   `LinkMLAdapter.load_file(path).extract_elements()` is called, **Then** each slot becomes
   a NormalizedElement with `source_name="linkml"`, correct `data_type`, and description.

2. **Given** a LinkML YAML schema with class definitions, **When** `extract_classes()` is
   called, **Then** each class becomes a SchemaClassPayload with `schema_format="yaml"` and
   `extraction_path="file"`.

3. **Given** `load_file("")`, **When** called, **Then** `ValueError` is raised.

---

### User Story 3 — Roundtrip Validation (Priority: P3)

A developer verifies that importing a JSON Schema or LinkML YAML and re-exporting it preserves
all semantic information — classes, fields, types, descriptions, required flags.

**Why this priority**: Quality-gates the export pipeline. Depends on US1 and US2.

**Independent Test**: Offline fixtures only — no backend required.

**Acceptance Scenarios**:

1. **Given** a simple JSON Schema fixture (no `anyOf`/`oneOf`), **When**
   `roundtrip_json_schema(path)` is called, **Then** `fidelity_score == 1.0` and
   `missing_classes` and `missing_elements` are both empty.

2. **Given** a minimal LinkML YAML schema, **When** `roundtrip_linkml(path)` is called,
   **Then** `fidelity_score == 1.0`.

3. **Given** a schema with complex composition (`anyOf` with three branches), **When**
   `roundtrip_json_schema(path)` is called, **Then** extraction does not crash and
   `fidelity_score` is in [0.0, 1.0]. **NOTE**: `anyOf`/`oneOf` fields degrade to
   `data_type="string"` (no type info lost in the set-based fidelity check, but
   semantic type precision is lost). Surfacing explicit per-field type-coercion warnings
   for `anyOf` is **deferred to feature 009-roundtrip-complex**.

4. **Given** `undata roundtrip <path> --format json`, **When** run, **Then** it prints a
   PASS/FAIL summary with fidelity score and warnings. Exits 0 on PASS, exits 1 on FAIL.

---

### Edge Cases

- JSON Schema with no `properties` (pure `$ref` forwarding): `extract_elements()` returns
  empty list — no crash.
- Circular `$ref` (A → B → A): cycle detection stops when `depth >= 5` (max 4 recursive
  resolutions); WARN logged; returns `"object"` for the unresolvable field.
- LinkML schema with `mixin: true` classes: included in `extract_classes()` output.
- Empty JSON Schema (`{}` or `{"$schema": "..."}`): returns empty lists.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: System MUST provide `GenericJSONSchemaAdapter` implementing the `SchemaAdapter`
  protocol (`load_file`, `extract_elements`, `extract_classes`, `get_version_info`) for
  draft-07/2019/2020 JSON Schema files.
- **FR-002**: `GenericJSONSchemaAdapter` MUST extract top-level `properties` as
  `NormalizedElement`s with `source_name="generic-json"`.
- **FR-003**: `GenericJSONSchemaAdapter` MUST extract `$defs` (or `definitions`) entries with
  `properties` as `SchemaClassPayload`s; their properties become additional `NormalizedElement`s.
- **FR-004**: `GenericJSONSchemaAdapter` MUST resolve in-document `$ref` (`#/$defs/<name>`)
  for type inference; circular refs MUST be caught when `depth >= 5` (max 4 recursive
  resolutions); unresolvable refs MUST yield `data_type="object"` with a WARN log.
- **FR-005**: System MUST provide `LinkMLAdapter` implementing the `SchemaAdapter` protocol
  for LinkML YAML schema files (via `linkml_runtime.loaders.yaml_loader`).
- **FR-006**: `LinkMLAdapter` MUST extract each `SlotDefinition` as a `NormalizedElement`
  with `source_name="linkml"`, mapping LinkML `range` to `NormalizedElement.data_type`.
- **FR-007**: `LinkMLAdapter` MUST extract each `ClassDefinition` as a `SchemaClassPayload`
  with `schema_format="yaml"` and `extraction_path="file"`.
- **FR-008**: System MUST provide `roundtrip_json_schema(path: str) -> RoundtripResult`
  that builds an in-memory LinkML schema from extracted elements, serializes to YAML,
  re-imports via `LinkMLAdapter`, and computes class/element fidelity.
- **FR-009**: System MUST provide `roundtrip_linkml(path: str) -> RoundtripResult`
  that re-serializes a LinkML YAML via `yaml_dumper`, re-imports, and computes fidelity.
- **FR-010**: `RoundtripResult` dataclass MUST contain: `fidelity_score: float` (0.0–1.0),
  `missing_classes: list[str]`, `missing_elements: list[str]`, `warnings: list[str]`.
- **FR-011**: System MUST expose `undata roundtrip <path> --format json|linkml`; exits 0 on
  `fidelity_score >= 1.0`, exits 1 otherwise.
- **FR-012**: All adapters MUST emit structured INFO logs on load; WARN on fidelity loss or
  cycle detection.
- **FR-013**: `GenericJSONSchemaAdapter` MUST handle both `$defs` (draft 2019+) and
  `definitions` (draft-07) as equivalent sources for type definitions.

### Key Entities

- **`GenericJSONSchemaAdapter`**: `SchemaAdapter`; `source_name="generic-json"`.
- **`LinkMLAdapter`**: `SchemaAdapter`; reads LinkML YAML; `source_name="linkml"`.
- **`RoundtripResult`**: dataclass; `fidelity_score`, `missing_classes`, `missing_elements`,
  `warnings`.
- **`roundtrip_json_schema(path)`** / **`roundtrip_linkml(path)`**: pure offline functions.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: `GenericJSONSchemaAdapter` returns ≥ 1 element for every JSON Schema fixture
  with at least one `properties` entry (DANDI and AIND bundled fixtures qualify).
- **SC-002**: `LinkMLAdapter` returns ≥ 1 element for any minimal LinkML YAML with ≥ 1 slot.
- **SC-003**: `roundtrip_json_schema()` on a simple fixture returns `fidelity_score == 1.0`.
- **SC-004**: `roundtrip_linkml()` on a minimal fixture returns `fidelity_score == 1.0`.
- **SC-005**: All new unit tests pass; all pre-existing tests remain unbroken (192 total at feature completion).
- **SC-006**: `ruff check` and `ruff format` pass on all new/modified files.
