## Implementation Phases

### Phase 1: Setup (version bump + fixtures)

Bump `pyproject.toml` to `2026.03.3`. Create two new test fixtures:
- `tests/fixtures/generic_schema_sample.json` — minimal JSON Schema with `properties`,
  `$defs`, `$ref`, `enum`, `required`.
- `tests/fixtures/linkml_sample.yaml` — minimal LinkML YAML with 2 classes and 4 slots.

### Phase 2: GenericJSONSchemaAdapter (US1)

**New file**: `src/undata/adapters/json_schema.py`

Key design:
- `load_file(path_or_url)` — reads JSON, stores as `self._schema: dict`; raises `ValueError`
  on empty path, `FileNotFoundError` on missing file.
- `_resolve_ref(ref, defs, depth=0)` — resolves `#/$defs/<name>` or `#/definitions/<name>`;
  returns `{}` when `depth >= 5` (max 4 recursive resolutions; cycle guard); logs WARN on cycle.
- `_infer_type(prop, defs)` — extends existing pattern from `dandi.py`; handles `$ref`.
- `extract_elements(mode="file")` — delegates to `_elements_from_schema()`.
- `extract_classes(mode="file")` — creates `SchemaClassPayload` per top-level title + each
  `$defs`/`definitions` entry with properties.
- `get_version_info()` — SHA-256 of raw JSON content.

Source name: `"generic-json"`. Handles both `$defs` and `definitions` keys.

### Phase 3: LinkMLAdapter (US2)

**New file**: `src/undata/adapters/linkml_adapter.py`

Key design:
- `load_file(path_or_url)` — uses `yaml_loader.load(path, target_class=SchemaDefinition)`;
  raises `ValueError` on empty path.
- `extract_elements(mode="file")` — iterates `schema.slots.items()`; maps `slot.range` →
  `data_type`; `slot.multivalued` → `multivalued`; `slot.required` → `required`;
  `source_local_id = f"{schema.name}.{slot_name}"`.
- `extract_classes(mode="file")` — iterates `schema.classes.items()`; creates
  `SchemaClassPayload` with `class_name`, `schema_format="yaml"`, `extraction_path="file"`;
  `element_source_local_ids` = slots owned by that class.
- `get_version_info()` — SHA-256 of raw YAML content; `version_tag` from `schema.version`.

Source name: `"linkml"`.

**Range → data_type mapping**:

| LinkML range | data_type |
|---|---|
| `string`, `str`, None | `"string"` |
| `integer`, `int`, `float`, `double` | `"number"` |
| `boolean`, `bool` | `"boolean"` |
| `Any`, `anyuri`, `uriorcurie` | `"object"` |
| any other name | `"object"` |
| (when `multivalued=True`) | `"array"` |

### Phase 4: Roundtrip module (US3)

**New file**: `src/undata/roundtrip.py`

```python
@dataclass
class RoundtripResult:
    fidelity_score: float          # 0.0-1.0
    missing_classes: list[str]
    missing_elements: list[str]
    warnings: list[str]

def roundtrip_json_schema(path: str) -> RoundtripResult: ...
def roundtrip_linkml(path: str) -> RoundtripResult: ...
```

`roundtrip_json_schema` algorithm:
1. `adapter = GenericJSONSchemaAdapter(); adapter.load_file(path)`
2. `elements = adapter.extract_elements(); classes = adapter.extract_classes()`
3. Build minimal `SchemaDefinition` from elements (reuse `linkml_gen._build_schema_from_elements()`
   or inline equivalent using `SlotDefinition` + `ClassDefinition`).
4. `yaml_str = yaml_dumper.dumps(schema)`
5. Write `yaml_str` to `tempfile.NamedTemporaryFile(suffix=".yaml")`
6. `la = LinkMLAdapter(); la.load_file(tmp.name)`
7. `re_elements = la.extract_elements(); re_classes = la.extract_classes()`
8. Compute: `missing_elements = {e.name for e in elements} - {e.name for e in re_elements}`
9. `missing_classes = {c.class_name for c in classes} - {c.class_name for c in re_classes}`
10. `fidelity_score = 1.0 - (len(missing_elements) + len(missing_classes)) / max(total, 1)`

`roundtrip_linkml` algorithm: simpler — load via `LinkMLAdapter`, `yaml_dumper.dumps()`,
re-load from tempfile, compare slot/class name sets.

### Phase 5: CLI extension + integration test

Add `roundtrip` Typer command in `cli.py`:

```bash
undata roundtrip <path> --format json|linkml
```

Prints:
```
Roundtrip fidelity: 1.00 (PASS)
  Missing elements: 0
  Missing classes:  0
```
Exits 0 on `fidelity_score >= 1.0`, exits 1 otherwise.
