# Implementation Plan: System Tutorials

**Branch**: `009-tutorials` | **Date**: 2026-03-11
**Spec**: `specs/009-tutorials/spec.md`

## Summary

Add a `tutorials/` directory at the repo root containing 7 Jupyter notebooks that walk
through every major undata workflow — from starting services to running migrations. Notebooks
are executable via `pytest --nbmake` and skip automatically when required services are
unavailable. No changes to any existing service code. New files only.

## Technical Context

**Language/Version**: Python 3.14 (tutorials venv matches project baseline)
**Primary Dependencies**:
- `nbmake ≥ 1.5` — runs `.ipynb` files as pytest tests
- `ipykernel` — Python 3 kernel for Jupyter
- `jupyter` — for interactive use
- `httpx ≥ 0.27` — HTTP client in notebooks (already project dependency)
**Storage**: N/A — tutorials create and delete backend data within each run; no new tables
**Testing**: `pytest --nbmake tutorials/` — all 7 notebooks pass when services are up;
auto-skip via in-notebook `pytest.skip()` when services unavailable
**Target Platform**: Developer workstation + CI; offline capable for T06
**Project Type**: Documentation + test suite (new `tutorials/` package)
**Performance Goals**: Each notebook ≤ 60 s; T06 (offline) < 5 s
**Constraints**: No new production deps; no changes to existing service code; no secrets in
committed files; `ruff check` passes on all Python code in cells
**Scale/Scope**: 7 notebooks (~150 cells total), 2 infrastructure files (conftest.py,
pyproject.toml), 1 README.md

## Implementation Phases

### Phase 1: Infrastructure (pyproject.toml + conftest.py + README.md)

**New file**: `tutorials/pyproject.toml`

```toml
[project]
name = "undata-tutorials"
version = "2026.03.0"
description = "Interactive tutorials for the undata system"
requires-python = ">=3.14"
dependencies = ["httpx>=0.27"]

[dependency-groups]
dev = [
    "nbmake>=1.5",
    "ipykernel",
    "jupyter",
    "pytest",
]

[tool.pytest.ini_options]
addopts = ["--nbmake", "--nbmake-timeout=60"]
testpaths = ["."]

[tool.ruff]
line-length = 100
target-version = "py314"
```

**New file**: `tutorials/conftest.py`

Provides session-scoped fixtures: `backend_url`, `migration_url`, `api_key`, `api_headers`,
`backend_available`, `migration_available`. These are used by native pytest tests; notebooks
read env vars directly since nbmake kernels don't receive pytest fixtures.

**New file**: `tutorials/README.md`

Documents: prerequisites, quick start commands, environment variables table, per-tutorial
services required, how to run interactively vs in CI.

### Phase 2: P1 Tutorials (T01–T03)

**T01: `01_getting_started.ipynb`** (~20 cells, ~5 min)
- Cell 2: Service check (skip if backend unavailable)
- Start services reference (markdown)
- `GET /health` — assert `{"status": "ok"}`
- API key usage (use pre-seeded dev key by default; markdown documents manual creation)
- `GET /api/v1/sources/` — list available schema sources
- `GET /api/v1/elements/?limit=5` — first 5 elements
- Cleanup: none (no writes)

**T02: `02_ingest_schemas.ipynb`** (~25 cells, ~10 min)
- Cell 2: Backend + ingestion check
- Run `undata ingest bids --extraction-mode code` via `subprocess`
- Run `undata ingest dandi --extraction-mode code` via `subprocess`
- `GET /api/v1/sources/` — confirm BIDS and DANDI sources appear
- `GET /api/v1/elements/?source=BIDS&limit=10` — confirm elements
- Cleanup: none (ingest is idempotent)

**T03: `03_browse_elements.ipynb`** (~25 cells, ~5 min)
- Cell 2: Backend check
- `GET /api/v1/elements/` — paginate through elements
- Filter by `source_name`, `data_type`, `required`
- `GET /api/v1/elements/{id}` — detail view
- `GET /api/v1/elements/{id}/history` — version history
- `POST /api/v1/aliases/detect` — find alias candidates
- Cleanup: none (read-only)

### Phase 3: P2 Tutorials (T04–T06)

**T04: `04_mappings_aliases.ipynb`** (~30 cells, ~10 min)
- Cell 2: Backend check
- `POST /api/v1/mappings/` — create an identity mapping between two elements
- `GET /api/v1/mappings/{id}` — verify mapping
- `POST /api/v1/aliases/` — create an alias group
- Run `undata detect-aliases --dry-run` via `subprocess`
- Cleanup: `DELETE /api/v1/mappings/{id}`, `DELETE /api/v1/aliases/{id}`

**T05: `05_linkml_export.ipynb`** (~20 cells, ~5 min)
- Cell 2: Backend check
- `POST /api/v1/schemas/` — create a named dynamic schema
- Run `undata generate-schema --output /tmp/undata-tutorial.yaml` via subprocess
- Load output with `LinkMLAdapter`, count elements
- Print first 5 classes
- Cleanup: `DELETE /api/v1/schemas/{id}`, `os.unlink("/tmp/undata-tutorial.yaml")`

**T06: `06_schema_roundtrip.ipynb`** (~20 cells, ~3 min)
- NO service check cell — fully offline
- Import `GenericJSONSchemaAdapter`, `LinkMLAdapter`, `roundtrip_json_schema`, `roundtrip_linkml`
- Load `../ingestion/tests/fixtures/generic_schema_sample.json`
- Print extracted elements
- Run `roundtrip_json_schema(path)` — assert `fidelity_score == 1.0`
- Load `../ingestion/tests/fixtures/linkml_sample.yaml`
- Run `roundtrip_linkml(path)` — assert `fidelity_score == 1.0`
- Run `!uv run undata roundtrip <path> --format json` via shell cell
- Cleanup: none

### Phase 4: P3 Tutorial (T07)

**T07: `07_data_migration.ipynb`** (~30 cells, ~15 min)
- Cell 2: Backend + migration-api check (skip if either unavailable)
- `POST /api/v1/diff` — diff two sources
- `POST /api/v1/pathways` (migration-api) — create a migration pathway
- `POST /api/v1/migrate` — run a batch migration
- `GET /api/v1/jobs/{id}` — poll for job completion
- Cleanup: `DELETE /api/v1/pathways/{id}`

### Phase 5: Validation

- `ruff check` all extracted Python from notebooks (via `jupyter nbconvert --to script`)
- Run `pytest --nbmake tutorials/ -v` with backend running — all P1+P2 pass

- Verify `pytest --nbmake tutorials/07_data_migration.ipynb` skips when migration-api is down
